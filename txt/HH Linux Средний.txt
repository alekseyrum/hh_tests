В директории /var/log вы хотите найти все текстовые файлы с расширением .log, в содержимом которых есть слово timeout, и получить список их имен. Какую команду используете?

правильный ответ:
++ 		: find /var/log -type f -name "*.log" -exec grep -l "timeout" {} \;

ошибки:
-- find /var/log -name "*.log" | grep -r "timeout"
-- grep -rl "timeout" /var/log -exec find -name "*.log"
-- find /var/log -type f -grep "timeout" > *.log
-- grep -l "timeout" $(find /var/log -type d -name "*.log")

По совету ГуглИИ: find /var/log -type f -name "*.log" -exec grep -l timeout {} \;
Но так тоже получается: find /var/log -name "*.log" | grep -r "timeout"
Или так: grep -rl "timeout" /var/log/*.log ,но про это ГуглИИ написал, что будут пропущены подкаталоги, содержащие *.log

{} — это плейсхолдер (заполнитель). Вместо него find подставляет пути к найденным файлам.
+ — это индикатор группировки. Он приказывает утилите find собрать все найденные файлы в один большой список и передать их команде grep за один раз.
[Сравнение с {} ;]
Вариант {} + (Группировка) выполняется: grep -l "timeout" файл1.log файл2.log файл3.log ...
Вариант {} \; (Поочередно) выполняется: find запускает отдельный процесс grep для каждого файла:
	grep -l "timeout" файл1.log
	grep -l "timeout" файл2.log
	...
Синтаксис:
find [где_искать] [критерии_поиска] -exec [команда] {} [способ_завершения]
способ_завершения - может быть только одним из двух: + или \;

Какой Bash-скрипт выведет имя .log-файла и количество строк в нём?

правильный ответ:
++ 		: for f in *.log; do wc -l "$f"; done

-l (lines) — показывает количество строк.
-w (words) — показывает количество слов.

Какая команда отобразит все открытые сетевые соединения и слушающие порты на текущем хосте?

правильный ответ:
++ 		: netstat -tunlp

ошибки:

-- passwd
-- df
-- ls

*-t (tcp) — показывает TCP-соединения.
-u (udp) — показывает UDP-соединения.
-n (numeric) — отображает адреса и порты в виде чисел, не пытаясь определить их доменные имена (ускоряет работу).

-p (program) — показывает PID (идентификатор) и имя программы, которая открыла этот порт (требуются права sudo).

Что означает строка прав -rw-r--r-- для обычного файла?

правильный ответ:
++ 		: Владелец может читать и изменять; группа и остальные - только 

ошибки:
-- Файл защищен от записи всеми пользователями
-- Все пользователи могут читать и выполнять 
-- Владелец и группа имеют полный доступ читать
-- Файл доступен только владельцу

Используя mtr для анализа соединения,вы заметили потерю пакетов начиная с определенного хопа и далее. Каков наиболее вероятный вывод?

правильный ответ:
++ 		: На данном или позже стоящем сетевом сегменте есть проблемы или фильтрация трафика

ошибки:
-- Неверная маска сети
-- Экземпляр mtr скомпилирован с ошибкой 
-- На сервере отключен SELinux
-- Ваш SSH-ключ не подходит к серверу

*Утилита mtr (My Traceroute) объединяет в себе функционал команд ping и traceroute, отправляя пакеты к целевому хосту и замеряя процент потерь (Loss%) и задержку на каждом промежуточном узле (хопе).

Что произойдет при выполнении команды rsync -a --delete src/ dest/ ?

правильный ответ:
-- Файлы, отсутствующие в src/, будут удалены из dest/

ошибки:
-- Удаленные файлы попадут в корзину
-- Старые версии сохранятся в архив
-- Файлы в src/ будут перезаписаны из dest/
-- Файлы будут скопированы, без удаления
