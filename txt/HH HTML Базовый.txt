Какая структура корректна для HTML-документа?

правильный ответ:
++ 		: <!DOCTYPE html><html><head><title></title></head><body></body></html>

ошибки:
-- <body><html><head><title></title></head></html>
-- <html><title><body></body></title></html>
-- <head><body></body></head>
-- <html><head><title></title><body></body></html>

Для чего используется спецсимвол &nbsp; ?

правильный ответ:
++ 		: Для символа неразрывного пробела

ошибки:
-- Для вставки точки с запятой
-- Для выделения текста жирным
-- Для отображения кавычек

правильный ответ:

ошибки:

Какая комбинация тега и атрибута ответит за отображение картинки на сайте?

Какая структура представляет собой корректную иерархию HTML-таблицы?

правильный ответ:
++ 		: <table> -> <tr> -> <td>

ошибки:
-- <table> -> <td> -> <th>
-- <table> -> <td> -> <tr>
-- <table> -> <row> -> <cell>
-- <table> -> <div> -> <td>

ошибки:

-- <ul><ul><li>Пукт</li></ul></ul>
-- <ul><li>Пункт<ul>Вложенный</ul></li></ul>
-- <li><li>Вложенный</li></li>
